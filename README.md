# baby-speech-bubble

赤ちゃんの写真に吹き出しコメントを合成し、PNG画像として保存できるWebアプリです。

## Features

- JPEG / PNG / WebP画像の読み込み
- 赤ちゃん向けコメントのランダム生成
- 好きなコメントの自由入力（最大40文字）
- Canvasによるブラウザ内画像合成
- PNG形式でのダウンロード
- ドラッグ＆ドロップとスマートフォン表示に対応
- 写真をサーバーへ送信しないプライバシー設計

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Cloudflare Workers

```bash
npm run deploy
```
